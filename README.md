## Featured project

### [PairRole](https://github.com/ogto90/pairrole)

A personal job research and application tracker built with Python, TypeScript, Streamlit and Supabase/PostgreSQL. I conceived and directed the project, using OpenAI Codex for implementation.

The public repository shows how I approach security in an AI-assisted application:

- **Untrusted network input:** destination validation, DNS pinning, redirect checks and response limits.
- **Untrusted documents:** isolated LaTeX compilation with no network or shell escape and bounded resources.
- **Sensitive data:** user-scoped authorization checks and database authorization regressions.
- **Delivery controls:** secret and dependency scans, CodeQL and deterministic security tests.
